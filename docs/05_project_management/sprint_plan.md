# WellNexa AI — 10-Sprint Agile Development Plan

| Sprint | Focus Area | Deliverables | Milestone Gate |
| :--- | :--- | :--- | :--- |
| **Sprint 1** | **Foundation & Auth** | Docker environment, PostgreSQL 16 + pgvector, Alembic setup, User/Role models, JWT auth flow. | Core Auth Running |
| **Sprint 2** | **Profile & Timeline** | Unified Health Profile, generic vitals tracking, auto-calculated BMI engine, Centralized Health Timeline. | Vitals & Timeline Running |
| **Sprint 3** | **Document Vault & OCR** | Encrypted document storage, SHA-256 integrity, OCR parameter parser for CBC/Glucose/Lipid/Thyroid panels. | Document OCR Running |
| **Sprint 4** | **Human-in-the-Loop OCR** | Report confirmation workflow, reference range boundary checking (`LOW`, `HIGH`, `CRITICAL`), delta trends. | Confirmed Reports Synced |
| **Sprint 5** | **Prescriptions & Reminders** | Medication inventory, dose logs, dynamic 30-day adherence scoring, central recurrence reminder engine. | Adherence & Alerts Running |
| **Sprint 6** | **Nutrition & Lifestyle** | Reference food database, meal logging with macro budgets, AI meal planner with diet filters (`JAIN`, `KETO`). | Nutrition Tracking Running |
| **Sprint 7** | **Fitness & Wellness** | Workout logging, 7-day activity metrics (steps, sleep, hydration), mood journal with 24/7 crisis hotlines. | Wellness Logging Running |
| **Sprint 8** | **AI Assistant & RAG** | Context assembler, clinical guidelines RAG retriever, emergency symptom triage, prompt injection defense. | AI Assistant Operational |
| **Sprint 9** | **Doctor Portal & Privacy** | Time-bound access grants (1 hr - 30 days), instant kill-switch revocation, GDPR JSON export, access audit logs. | Doctor Portal Running |
| **Sprint 10**| **Dashboard & Release** | Single home aggregation API ($<200\text{ms}$), Flutter cross-platform UI, demo seed scripts, capstone defense. | System Release & Defense |
