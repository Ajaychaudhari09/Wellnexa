# WellNexa AI — Stakeholder Analysis

| Stakeholder Group | Role & Primary Interest | Key Expectations | Engagement & Touchpoints |
| :--- | :--- | :--- | :--- |
| **Patient / End User** | Primary consumer tracking health, vitals, prescriptions, and lab reports. | Fast app performance, easy document upload, reliable medicine reminders, plain-language report summaries, strict privacy. | Mobile/Web Flutter Client, Notifications, Privacy Center. |
| **Healthcare Professional (Doctor / Clinician)** | Reviewer of patient clinical history during consultations. | Fast longitudinal summary, confirmed lab reports, active medications, allergy warnings, ability to record consultation notes. | Doctor Portal, Time-bound Access Tokens, QR Passes. |
| **System Administrator** | Operational integrity, security oversight, and compliance auditing. | Audit trail inspection, rate limiting monitoring, role-based access management, server health telemetry. | Admin Compliance API, Swagger Docs, Server Logs. |
| **Academic Guide / Evaluation Committee** | Evaluation of software engineering rigor, architectural soundess, and research validity for MCA Capstone. | Complete SDLC documentation, ER/UML models, clean code architecture, automated testing (80%+), reproducible demo. | Academic Capstone Documentation, GitHub Repository, Viva Demo. |
| **Future System Maintainers** | Long-term code maintainability and scalability. | Clean modular monolith architecture, typed schemas, automated migrations (Alembic), decoupled domain modules. | Developer Guide, ADRs, Code Base Comments. |
